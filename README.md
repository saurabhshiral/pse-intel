# PSE Intel

A professional intelligence platform for Accenture AMS teams monitoring Puget Sound Energy and the US utility sector. Aggregates RSS news feeds, tracks leadership changes over time, and delivers weekly AI-summarized email digests.

## Repo Structure

| File / Folder | Description |
|---|---|
| `index.html` | Self-contained frontend — all CSS & JS inline, no build tools |
| `monitor.py` | Scrapes PSE leadership & board pages, diffs against previous snapshot |
| `digest.py` | Fetches RSS feeds, calls Groq to summarize, sends HTML email via Office 365 |
| `leadership_snapshot.json` | Auto-generated by `monitor.py`; pre-seeded with current PSE team |
| `.github/workflows/weekly.yml` | GitHub Actions: runs monitor + digest every Monday 7 AM Pacific |

## Run Locally

**Open the dashboard:**
```
# Just open index.html in any browser — no server needed
open index.html        # macOS
start index.html       # Windows
```

**Generate initial leadership snapshot:**
```bash
pip install requests beautifulsoup4
python monitor.py
```
This fetches live data from PSE's website and writes `leadership_snapshot.json`. Commit that file so Tab 4 (Leadership Watch) works on first load. GitHub Actions keeps it updated weekly after that.

**Send a digest manually:**
```bash
pip install requests feedparser
export GROQ_API_KEY=your_key_here
export OUTLOOK_EMAIL=you@accenture.com
export OUTLOOK_PASSWORD=your_password
python digest.py
```

## Deploy

### GitHub Pages (recommended — free, instant)
1. Push this repo to GitHub
2. Go to **Settings → Pages → Source → Deploy from branch**
3. Choose `main` / `(root)` → **Save**
4. Live at `https://USERNAME.github.io/pse-intel` within ~60 seconds

### Vercel (alternative)
1. Go to [vercel.com](https://vercel.com) → **New Project** → import this repo
2. Click **Deploy** — no build config needed
3. Live on a `*.vercel.app` URL immediately

## GitHub Secrets to Add

Go to **Settings → Secrets and variables → Actions → New repository secret**:

| Secret | Where to get it |
|---|---|
| `GROQ_API_KEY` | [console.groq.com](https://console.groq.com) → API Keys → Create (free, no card) |
| `OUTLOOK_EMAIL` | Your Accenture email address |
| `OUTLOOK_PASSWORD` | Your Accenture email password (or app password if MFA is enabled) |

## `leadership_snapshot.json`

Pre-populated with the PSE leadership team as of August 2026. After the first `monitor.py` run:
- Commit the generated file: `git add leadership_snapshot.json && git commit -m "chore: initial leadership snapshot"`
- GitHub Actions automatically commits an updated snapshot every Monday and pushes it, keeping the Leadership Watch tab current without any manual work.

## How Leadership Watch Works

`monitor.py` scrapes `pse.com/about-us/leadership` and `pse.com/about-us/board-of-directors`, extracts name + title pairs, and diffs against the previous snapshot. Detected changes (added, removed, title changed) are written into `leadership_snapshot.json` under the `changes` key. The frontend reads that file and renders the changes with colored pills (green = added, red = removed, amber = changed). The GitHub Actions workflow exits with code 1 if changes are found, making it easy to add a Slack/Teams notification step.
